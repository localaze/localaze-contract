# Security

Please report security problems privately, not in a public issue.

**How:** use GitHub's [private vulnerability reporting](https://github.com/localaze/localaze-contract/security/advisories/new) for this repository. Say what the problem is, how to reproduce it, and which versions it affects.

**What to expect:** an acknowledgement within three working days, and a fix or a plan within thirty. You will be credited in the advisory unless you would rather not be.

**Supported versions:** the latest release. While the SDKs are at `0.x`, fixes ship as a new version rather than a backport.

Problems in the Localaze server itself, rather than in this SDK, can be reported the same way here; they will be passed on.
